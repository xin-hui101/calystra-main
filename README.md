# 📸 Calystra Photography Studio Management App

A mobile photography studio management app built with **Flutter** and **Firebase**, designed to streamline the photography booking and studio management process for both customers and studio administrators.

---

## ✨ Features

### 👤 Customer
- **Browse Portfolios**: Explore the studio's photography portfolios
- **Services & Booking**: View available photography services and make bookings
- **Booking Tracking**: Track the real-time status of bookings
- **Feedback & Reviews**: Submit feedback and reviews after a session

### 🛠️ Admin
- **Booking Management**: View, approve, update, and manage customer bookings
- **Portfolio Management**: Add, update, and maintain studio portfolios
- **Feedback Monitoring**: View and monitor customer feedback and reviews

### 🗺️ Google Maps Integration
- Displays the studio location on an interactive map so customers can easily find the studio
